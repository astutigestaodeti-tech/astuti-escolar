## Antes de começar

Use sua própria conta, confira escola, turma e ano, e confirme o segundo fator quando solicitado. Utilize dados fictícios no treinamento. Proteja documentos nominais e não copie dados de saúde para campos gerais. Os documentos A4 podem ser impressos ou salvos como PDF pelo navegador. Capturas de tela somente após validação por Jefferson.
